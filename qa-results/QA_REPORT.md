## Failed Tests

### TC-07: 검색어 입력 후 결과 표시
- **Expected**: "transformer" 검색 시 관련 논문 목록 표시
- **Actual**: "검색 결과가 없습니다 (0개)" 표시
- **원인**: 비로그인 상태에서 `GET /api/paper/?q=transformer` 호출 시 **401 Unauthorized** 반환. `/api/auth/refresh` 재시도도 401.
- **UX 문제**: 인증 실패인데 "검색 결과가 없습니다"로 표시되어 사용자가 검색어 문제로 오해 가능
- **증거**: [TC-07/search-results.png](TC-07/search-results.png)
- **개선 제안**: 401 에러 시 "로그인 후 검색 결과를 확인할 수 있습니다" 등 별도 안내

### TC-10: 로그인 페이지 요소 정상 표시
- **Expected**: 개인정보처리방침, 이용약관 링크 정상 동작
- **Actual**:
  - 개인정보처리방침, 이용약관 링크 `[disabled]` + `href="#"` — 실제 페이지 없음
  - 접근성(aria) 텍스트에 "**Kakao** 계정으로 로그인" 이라고 명시되어 있으나 실제 버튼은 **GitHub** — aria 불일치
- **증거**: [TC-10/login-elements.png](TC-10/login-elements.png)

### TC-11: 프로토타입 버전 체험 링크 동작
- **Expected**: 클릭 시 로그인 없이 앱 진입
- **Actual**: 클릭해도 아무 반응 없음. `<p>` 태그로 구현되어 있어 이벤트 핸들러 없음
- **증거**: [TC-11/prototype-click.png](TC-11/prototype-click.png)
- **개선 제안**: `<button>` 또는 `<a>` 태그로 변경 후 게스트 로그인 처리 연결 필요

## Observations

### 1. 설정 vs 마이페이지 인증 처리 불일치 (TC-04)
- **마이페이지**: URL /mypage로 이동 후 로그인 모달 오버레이 표시
- **설정**: /login 페이지로 완전 리다이렉트
- 동일한 "로그인 필요" 상황에서 동작이 달라 사용자 경험 일관성 저하

### 2. 모바일 로그인 모달 하단 잘림 (TC-05, TC-06)
- 390px 모바일에서 로그인 모달이 뷰포트 하단에서 잘려 약관 링크, 프로토타입 체험 텍스트 미노출
- 모달 내 스크롤 가능 여부 확인 필요

### 3. 비로그인 상태 검색 API 일괄 401
- 검색 기능 전체(기본 목록, 키워드 검색, 태그 필터)가 인증 없이 동작하지 않음
- 프로토타입/데모 환경임을 감안해도 검색 결과 미표시는 앱의 핵심 기능 데모가 불가한 상황

### 4. 반응형 레이아웃 전반적으로 안정적
- 360px ~ 1920px 전 구간에서 레이아웃 깨짐, 요소 overflow, 가로 스크롤 없음
- 모바일/태블릿/데스크탑 전환(사이드바 ↔ 하단탭바) 정상 동작
