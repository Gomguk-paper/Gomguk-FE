## Observations

1. **레이아웃 전반적으로 안정적** — 768~1024px 전 구간에서 깨짐, overflow, 가로 스크롤 없음. 사이드바·피드·설정 모두 일관된 레이아웃 유지.

2. **TC-04 수정 확인** — 이전 QA에서 401로 실패했던 키워드 검색이 이번 테스트(로그인 상태)에서 정상 동작. 로그인 후 검색 기능은 복구됨.

3. **태그/정렬 API 인증 불일치** — 키워드 검색(PASS)과 태그 필터(FAIL)가 다른 인증 처리 경로를 타는 것으로 추정. 백엔드 미들웨어 적용 범위 확인 필요.

4. **Trending Topics 브레이크포인트** — 전 태블릿 구간에서 미노출. 의도적 숨김인지, 아니면 브레이크포인트 조정이 필요한지 확인 필요.

5. **짧은 세션 만료 시간** — 테스트 환경 기준 ~25분. 실서비스라면 사용자 경험 저하 가능. refresh token 처리 검토 권장.
